Qualitätsstufen

Die Qualitätsstufen, die Aufträge als Mindestqualität für Material verlangen können.

Stufen

Die Mindestqualität einer Stufe, die bereits von Aufträgen verwendet wird, kann nicht mehr geändert werden. Eine verwendete Stufe kann nur deaktiviert, nicht gelöscht werden.

Großbuchstaben, Ziffern und Unterstriche, beginnend mit einem Buchstaben.

0 bis 1000. Bei einer Stufe, die bereits von Aufträgen verwendet wird, bleibt sie unverändert.

Eine inaktive Stufe wird für neue Aufträge nicht mehr angeboten.

Die Grundstufe bleibt aktiv und behält die Mindestqualität 0.

Diese Qualitätsstufe endgültig löschen?

Eine Stufe, die von Aufträgen verwendet wird, kann nicht gelöscht werden. Deaktiviere sie stattdessen.
